# Книги, которые меняют взгляд

Каталог книг-конспектов для взрослых: **10 сфер жизни, 69 книг**.

## Что внутри

- `index.html` — приложение (оболочка): верхнее меню на десктопе, выдвижное — на смартфоне; книги открываются во вкладках.
- `catalog.html` — каталог: сферы жизни, карточки книг, приоритет звёздами и блок «С чего начать».
- `<Книга>.html` — страницы книг: разбор по главам (суть, «Что важно понять», пример из книги, цитата, вывод).
- `book-style.css`, `book-theme.js` — общие стили и логика.

### Редакционное правило для конспектов

Если в главе есть действительно важные и определяющие детали — конкретные правила, рекомендации, формулы, алгоритмы или тезисы, которые полезно прочитать почти в исходной формулировке, — добавляйте отдельный блок:

```html
<div class="excerpt">
  <span class="tag">Выдержка из книги</span>
  Здесь — точная или аккуратно переведённая формулировка ключевого правила.
</div>
```

Используйте «Выдержку из книги» экономно: только для опорных деталей, которые теряются при обычном пересказе. Не превращайте страницу в коллекцию цитат и не добавляйте блок ради каждого интересного предложения.

## Редакционный skill: добавление новых книг

При добавлении книги в этот проект:

1. Сначала проверьте, нет ли уже книги с теми же идеями в каталоге.
2. Создайте подробную HTML-страницу в существующем стиле: hero, toc, разбор по главам/темам, ключевые идеи, итог и footer.
3. Не выдумывайте библиографию, главы, даты, цитаты или содержание. Если данных нет — честно укажите ограничение.
4. Обновите одновременно `index.html` и `catalog.html`.
5. Проверьте все ссылки, структуру HTML и `git diff --check`.
6. После успешной проверки автоматически выполните `git add -A`, создайте осмысленный коммит и `git push origin main`.

Пуш является частью стандартного процесса добавления книги; перед ним нужно убедиться, что в рабочем дереве нет чужих незакоммиченных изменений.

## Возможности

- Светлая (бежевая) и тёмная (графит) темы с переключателем.
- Отметки «прочитано» (хранятся локально в браузере) и счётчик.
- Прогресс чтения: полоса + плашка «% · глава N/M», кнопка «Наверх».
- Верхнее меню с выпадающими списками (десктоп); выдвижное меню (смартфон).
- В альбомной ориентации смартфона — единая нижняя панель (меню + тема + управление книгой).

## Запуск

Открыть `index.html` в браузере (двойным кликом) или через локальный сервер.

## Публикация в интернете (GitHub Pages)

Сайт статический, поэтому публикуется бесплатно за пару минут.

**1. Склонировать репозиторий**

```bash
git clone git@github.com:SergeiTarasovDev/Books40.git
cd Books40
```

Если SSH-ключ не настроен, используйте HTTPS-ссылку: `https://github.com/SergeiTarasovDev/Books40.git`.

**2. Включить GitHub Pages**

- Откройте репозиторий на GitHub → **Settings** → **Pages**.
- **Build and deployment** → Source: **Deploy from a branch**.
- Branch: **main**, папка **/ (root)** → **Save**.
- Репозиторий должен быть **публичным** — на бесплатном тарифе Pages доступны только для публичных репозиториев.

**3. Открыть в любом браузере**

- Через ~1 минуту сайт доступен по адресу `https://sergeitarasovdev.github.io/Books40/`.
- Открывается в любом браузере на компьютере, планшете и телефоне — устанавливать ничего не нужно.
- При каждом `git push` в ветку `main` сайт обновляется автоматически.

**Локально без публикации**

Откройте `index.html` двойным кликом — сайт работает и без интернета.
